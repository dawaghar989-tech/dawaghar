## Responsible Use of Ayurvedic Products

Ayurvedic formulations may contain active ingredients. Some herbs can cause side effects or interact with prescription medicines. For this reason, responsible use is important.

Consider these precautions:

- Follow the instructions provided with the product.
- Do not take more than the recommended amount.
- Consult a qualified healthcare professional if you have an existing medical condition.
- Seek advice before combining herbal products with prescription medicines.
- Pregnant or breastfeeding individuals should consult a healthcare professional before using Ayurvedic products.
- Do not replace prescribed treatment with herbal products without medical guidance.

If you experience an unexpected reaction, stop using the product and seek appropriate medical advice.
